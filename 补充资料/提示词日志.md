# 提示词日志（人机协同 / AI 交互迭代记录）

## 1. 多模态视觉识别提示词（MiniMax-M3）
系统提示（节选）：
```
你是建筑工地安全巡检的视觉识别模块。请只输出一个 JSON 对象……
分析这张工地现场照片，返回：
summary, findings[{item,status,confidence,risk_level,evidence,needs_review}], risks[], pending_review[]
无法从照片判断的项，confidence 应较低且 needs_review 设为 true。
```
迭代点：
- 初版直接输出自然语言，导致下游难以解析；改为强制 JSON 后稳定。
- 初版对“无法判断”仍给出高置信度；加入“无法判断→低置信度+需人工确认”规则后，人工复核项更准确。

## 2. 整改建议生成提示词（文本层）
系统提示（节选）：
```
你是建筑工地安全巡检助手。请根据识别结果和规范，生成简洁、可执行的隐患描述和整改措施，并给出风险等级；
对低置信度或信息不足的项明确标注“需人工确认”。
```
输入数据：视觉识别摘要 + 结构化 findings + OCR 现场标牌 + 安全规范卡片。

## 3. 纠偏与回写
人工动作：confirm / correct；记录字段：review_id、action、note、corrected、ts。
示例日志：
```json
{"review_id":"a1b2c3d4e5","action":"correct","note":"现场已有动火证，未入画","corrected":"动火作业状态改为已持证","ts":"2026-08-29T16:40:00"}
```
